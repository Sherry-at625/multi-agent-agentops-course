## 三、调度计划（分派指令要点）

| 时序 | 分派对象 | 分派指令要点（写入下游上下文） |
|---|---|---|
| 1 | Data Engineer | 输入 `data/retail_sales_raw.csv`（UTF-8 BOM）；先输出探查结果（规模 3654、缺失、重复、数值分布）再清洗；产物 D1/D2；按交接摘要格式回报五类处理条数 + 待人工确认清单 |
| 2 | Analyst | 接手先核对 D1 行数与列完整性；再算总体 + 月度 / 品类 / 地区 / 分层四维分组；产物 D3/D4；洞察 3—5 条且每条带数值与口径 |
| 3 | Reviewer | 只读模式，不改任何上游文件；按 A/B/C 共 11 项核查；独立复算总销售额 / 总利润 / 订单数；产物 D5 |
| 4 | Reporter | 仅在 D5 结论为「通过 / 有条件通过」后启动；只引用 D3 数字；产物 D6/D7 |

**并行约束**：本流水线为**串行依赖型**（每环节消费上一环节的文件），不存在可并行的节点；编排者不得为缩短耗时把 T1/T2 合并给同一 Agent，否则质检失去独立复算对象。

**回退路由规则**（质检不通过时）：

- 数据错误类（负利润残留、重复行、销售额口径不符）→ 退回 **Data Engineer**，并连带要求 Analyst 重跑 T2/T3；
- 指标不可复算 / 分组之和不等于总体 / 图表与 JSON 不一致 → 退回 **Analyst**；
- 结论超出数据（因果推断、编造指标）→ 退回 **Reporter**；
- 同一环节退回 ≥ 2 次 → 暂停流水线，向用户说明卡点与所需人工决策。
