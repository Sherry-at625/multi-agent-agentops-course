# 全局项目规则（Global Rules）

> 适用平台：Trae IDE / Trae SOLO、WorkBuddy
> 使用方式：在 Trae 中放入项目根目录 `.trae/rules/global_rules.md`（或 AGENTS.md）；在 WorkBuddy 中作为项目知识库 / 首条系统说明粘贴。所有子智能体共享本规则。

## 1. 项目背景

- 课程案例：区域连锁零售 2024—2025 年订单数据分析。
- 目标：由一组分工明确的智能体协作，完成「数据清洗 → 指标分析 → 可视化 → 质量校验 → 报告交付」全流程，最终产出一份可阅读的中文分析报告与配套图表、清洗后数据。
- 输入数据：`data/retail_sales_raw.csv`（约 3600 行，已刻意注入缺失值、重复记录、日期格式不统一、负利润、异常数量等问题）。

## 2. 数据字典

| 字段 | 含义 | 备注 |
|---|---|---|
| order_id | 订单编号 | 重复录入时整行重复 |
| order_date | 下单日期 | 存在 `YYYY-MM-DD` 与 `YYYY/MM/DD` 两种格式，存在缺失 |
| region | 大区 | 华北 / 华东 / 华南 / 西南 / 东北 / 华中 |
| city | 城市 | 归属对应大区 |
| category | 一级品类 | 电子产品、家居用品、服装鞋帽、食品饮料、美妆个护、办公用品 |
| sub_category | 二级品类 | |
| customer_segment | 客户分层 | 新客 / 老客 / 会员，存在缺失，缺失回填为「未知」 |
| quantity | 购买数量 | 存在 0、负数等录入错误 |
| unit_price | 单价（元） | |
| discount | 折扣率 | 0、0.05、0.10、0.15、0.20 |
| sales_amount | 销售额（元） | 复核公式：quantity × unit_price × (1 − discount) |
| cost | 成本（元） | |
| profit | 利润（元） | 存在负利润异常记录 |
| payment_channel | 支付渠道 | 微信 / 支付宝 / 银行卡 / 现金 / 会员储值 |
| delivery_mode | 配送方式 | 门店自提 / 快递配送 / 同城速达 |

## 3. 通用输出规范

1. 所有面向用户的文字使用简体中文；代码、字段名、命令、文件路径使用半角英文与符号。
2. 金额单位统一为「元」，保留两位小数；百分比保留一位小数；图表必须有标题、坐标轴单位、图例。
3. 所有结论必须能回溯到数据：先给指标数值，再给判断；禁止在没有数据支撑时写「显著增长」「表现优异」等定性结论。
4. 文件命名使用小写英文与下划线，产物按目录归档：
   - 清洗后数据：`data/retail_sales_cleaned.csv`
   - 清洗报告：`outputs/cleaning_report.json`
   - 指标结果：`outputs/summary_metrics.json`
   - 图表：`outputs/charts/`
   - 最终报告：`outputs/零售销售数据分析报告.md`（或由 WorkBuddy 导出 Word / PDF）
5. 每一步执行都要留下可追溯记录：输入文件、执行命令、关键中间结果、异常与处理方式，供 AgentOps 观测与回放。

## 4. 智能体交接协议

- 上游智能体向下游交付时，必须同时给出：**产物文件路径 + 一段结构化摘要（关键指标、口径、遗留问题）**。
- 下游智能体不得假设上游已经处理过某类问题；接手后先核对数据质量与口径，再开展本环节工作。
- 发现上游错误时，不擅自修改上游产物，而是记录问题并交回编排者（Orchestrator）决定回退到哪个环节。
- 跨智能体传递的数字必须与文件中的数值一致，禁止二次估算。

## 5. 质量底线（所有智能体共同遵守）

- 不编造数据、不虚构图表；样本量、时间范围必须写明。
- 代码必须可重复运行；随机过程固定随机种子。
- 遇到权限、依赖、网络问题，先报告错误信息，再给出修复尝试，不静默跳过步骤。
- 不执行与本任务无关的文件删除、系统命令；高风险操作先请求人工确认。

## 6. 角色一览

| 角色 | 平台建议 | 职责 |
|---|---|---|
| Orchestrator 编排者 | Trae Agent 窗口 / WorkBuddy Plan 模式 | 拆解任务、分派角色、回收产物、协调回退、汇总状态 |
| Data Engineer 数据工程 Agent | Trae IDE / SOLO | 读取原始数据、清洗、去重、口径复核、输出清洗报告 |
| Analyst 分析可视化 Agent | Trae IDE / SOLO | 计算指标、分组对比、生成图表与数据洞察 |
| Reviewer 质检评审 Agent | WorkBuddy Ask 只读模式 | 校验数据质量、口径一致性、图表与结论匹配、出具质检意见 |
| Reporter 报告撰写 Agent | WorkBuddy | 汇总指标、图表与质检意见，撰写并交付最终分析报告 |
